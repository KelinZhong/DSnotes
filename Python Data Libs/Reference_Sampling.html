§1 – Simple Random Sampling (SRS)#

Intuition: Every unit has an equal probability of selection – the “lottery” model. The baseline all other methods compare against. In DS interviews this appears most often disguised as: “implement a train/test split without using sklearn.”

Key properties:

  • Unbiased estimator of the population mean

  • Variance decreases as 1/n

  • df.sample(frac=1) shuffles; slicing gives the split

Confidence Interval:

\[\bar{x} \pm z \cdot \frac{s}{\sqrt{n}} \quad (z = 1.96 \text{ for 95\%, valid for } n \geq 30)\]

Interview prompt: “Without using sklearn, implement a function that splits a DataFrame into train and test sets given a test fraction. Ensure it is reproducible and verify there is no overlap between the two sets.”

# ── Interview task: train_test_split from scratch ─────────────────────────────
def train_test_split(df, test_frac=0.2, seed=42):
    """
    Random train/test split without sklearn.
    Shuffles once then slices -- O(n), no index collisions.
    Column-agnostic: works for any number of feature columns.
    """
    shuffled = df.sample(frac=1, random_state=seed).reset_index(drop=True)
    n_test   = int(len(shuffled) * test_frac)
    test     = shuffled.iloc[:n_test].reset_index(drop=True)
    train    = shuffled.iloc[n_test:].reset_index(drop=True)
    return train, test

Common mistakes:

  • Forgetting random_state / seed – split is not reproducible

  • Using df.index directly after filtering – duplicated indices cause silent bugs in .iloc vs .loc; always reset_index(drop=True) after a split

  • Checking overlap by row content instead of ID – two different rows can have identical values

§2 – Stratified Sampling#

Intuition: Divide the population into non-overlapping strata and sample independently within each. Guarantees every subgroup is represented in proportion to its size in the population. In DS interviews this is almost always framed as a class-imbalance problem – a minority class can disappear entirely from a test set under plain SRS.

Key properties:

  • Preserves class proportions in both train and test

  • Variance is lower than SRS when strata have different means

  • Disproportional allocation = deliberately oversample a minority class

Confidence Interval:

\[\bar{x}_{st} = \sum_h W_h \bar{x}_h, \quad SE = \sqrt{\sum_h W_h^2 \frac{s_h^2}{n_h}}\]

where \(W_h = N_h / N\) is the stratum weight.

Interview prompt: “You have a dataset with 80/15/5 class imbalance. Implement a stratified train/test split without sklearn that preserves those proportions. Verify the result.”

    'feature1': rng.normal(0, 1, N),
    'feature2': rng.exponential(scale=5, size=N).round(2),   # second metric
    'label'   : labels,

print("Population class distribution:")

# ── Interview task: stratified_split from scratch ─────────────────────────────
def stratified_split(df, target_col, test_frac=0.2, seed=42):
    """
    Stratified train/test split preserving class proportions.
    Samples test_frac from each stratum independently.
    Column-agnostic: all non-target columns are carried through.
    """
    train_parts, test_parts = [], []
    for _, grp in df.groupby(target_col):
        shuffled = grp.sample(frac=1, random_state=seed)
        n_test   = int(len(shuffled) * test_frac)
        test_parts.append(shuffled.iloc[:n_test])
        train_parts.append(shuffled.iloc[n_test:])
    train = pd.concat(train_parts).sample(frac=1, random_state=seed).reset_index(drop=True)
    test  = pd.concat(test_parts).sample(frac=1, random_state=seed).reset_index(drop=True)
    return train, test

train, test = stratified_split(df, target_col='label', test_frac=0.2, seed=42)

# ── Verify proportions are preserved ──────────────────────────────────────────
print("\nClass proportions across splits:")
comparison = pd.DataFrame({
    'population': df['label'].value_counts(normalize=True).round(3),
    'train'     : train['label'].value_counts(normalize=True).round(3),
    'test'      : test['label'].value_counts(normalize=True).round(3),
}).sort_index()
print(comparison)

for label, grp in df.groupby('label'):
    n     = target_n[label]
    repl  = len(grp) < n                                                # oversample if needed
    parts.append(grp.sample(n=n, replace=repl, random_state=42))
balanced = pd.concat(parts).reset_index(drop=True)

# ── §2 DataFrame API: stratified_split_df ────────────────────────────────────
def stratified_split_df(df, target_col, cols, stat_fn=None, test_frac=0.2, seed=42):
    """
    Stratified split that accepts a DataFrame, column list, and a stat function.

    Parameters
    ----------
    df         : pd.DataFrame
    target_col : str           -- stratification column (class label)
    cols       : list[str]     -- metric columns to summarise
    stat_fn    : callable or None
                 Signature: stat_fn(arr: np.ndarray) -> scalar
                 Default: np.mean
    test_frac  : float
    seed       : int

    Returns
    -------
    train, test : pd.DataFrames
    summary     : pd.DataFrame  -- stat_fn applied to each col in each split
    """
    if stat_fn is None:
        stat_fn = np.mean

    train_parts, test_parts = [], []
    for _, grp in df.groupby(target_col):
        shuffled = grp.sample(frac=1, random_state=seed)
        n_test   = int(len(shuffled) * test_frac)
        test_parts.append(shuffled.iloc[:n_test])
        train_parts.append(shuffled.iloc[n_test:])
    train = pd.concat(train_parts).sample(frac=1, random_state=seed).reset_index(drop=True)
    test  = pd.concat(test_parts).sample(frac=1, random_state=seed).reset_index(drop=True)

    summary = pd.DataFrame({
        'population': df[cols].apply(lambda s: stat_fn(s.values)),
        'train'     : train[cols].apply(lambda s: stat_fn(s.values)),
        'test'      : test[cols].apply(lambda s: stat_fn(s.values)),
    }).round(4)
    return train, test, summary

  • Using df.groupby().apply(lambda x: x.sample(...)) in pandas 3.x – the groupby key is dropped from the result; use an explicit loop instead

§3 – Systematic Sampling#

Intuition: Sort the population by a natural ordering, pick a random start in [0, k), then select every k-th unit. Simpler than SRS for large ordered data (one scan, no lookup table) and equally precise when the order is random. The single failure mode: if the data has a periodic pattern with the same period as k, the sample is catastrophically biased.

Step size: k = N / n (round to nearest integer). Random start in [0, k).

Confidence Interval: Approximate as SRS when autocorrelation is low.

\[\text{CI} \approx \bar{x} \pm 1.96 \cdot \frac{s}{\sqrt{n}}\]

Interview prompt: “You have a time-ordered log of 1 million server events. Implement systematic sampling to draw 10,000 for analysis. Then explain and demonstrate the main failure mode.”

import numpy as np
import pandas as pd

rng = np.random.default_rng(42)

# ── Simulate time-ordered event log (two metric columns) ──────────────────────
N = 1_000_000
df_log = pd.DataFrame({
    'timestamp'    : pd.date_range('2024-01-01', periods=N, freq='s'),
    'response_ms'  : rng.exponential(scale=200, size=N).round(1),
    'payload_bytes': rng.integers(100, 5_000, size=N).astype(float),  # second metric
})
metric_cols = ['response_ms', 'payload_bytes']

# ── Systematic sampling ───────────────────────────────────────────────────────
n     = 10_000
k     = N // n                                                           # step = 100
start = int(rng.integers(0, k))                                          # random start in [0, k)
indices    = np.arange(start, N, step=k)[:n]

sample_sys = df_log.iloc[indices].reset_index(drop=True)                 # pandas (all columns)
sample_np  = df_log['response_ms'].values[indices]                       # NumPy (single col)

print(f"Population : {N:,} events")
print(f"Step k     : {k},  Random start: {start},  Sample n: {len(sample_sys):,}")
print(f"Time range : {sample_sys['timestamp'].iloc[0]} -> {sample_sys['timestamp'].iloc[-1]}")

# ── Confidence Intervals for multiple columns ──────────────────────────────────
print(f"\n{'Column':<16} {'Sample mean':>14} {'95% CI':>28} {'True mean':>12}")
print("-" * 74)
for col in metric_cols:
    x    = sample_sys[col].values
    mean = x.mean()
    ci   = (mean - 1.96*x.std(ddof=1)/np.sqrt(n),
             mean + 1.96*x.std(ddof=1)/np.sqrt(n))
    true_mean = df_log[col].mean()
    print(f"{col:<16} {mean:>14.1f}   ({ci[0]:.1f}, {ci[1]:.1f})  {true_mean:>12.1f}")

# ── Failure mode: check autocorrelation at lag k for each column ──────────────
print(f"\nAutocorrelation at lag k={k}:")
for col in metric_cols:

print(f"Periodic signal -- sample mean : {periodic_samp.mean():.1f}  <- biased")
print(f"Bias magnitude                 : {abs(periodic_samp.mean()-periodic.mean()):.1f}")

DataFrame API: systematic sampling with a stat function over selected columns.

# ── §3 DataFrame API: systematic_sample_df ───────────────────────────────────
def systematic_sample_df(df, cols, n, stat_fn=None, seed=42):
    """
    Systematic sample from a DataFrame, returning sample + per-column stats.

    Parameters
    ----------
    df      : pd.DataFrame  -- must already be in the desired order
    cols    : list[str]     -- metric columns to summarise
    n       : int           -- desired sample size
    stat_fn : callable or None  (default np.mean)
    seed    : int           -- controls the random start only

    Returns
    -------
    sample  : pd.DataFrame
    summary : pd.DataFrame  -- stat_fn applied to sample vs population
    """
    if stat_fn is None:
        stat_fn = np.mean

    N       = len(df)
    k       = N // n
    rng_s   = np.random.default_rng(seed)
    start   = int(rng_s.integers(0, k))
    indices = np.arange(start, N, step=k)[:n]
    sample  = df.iloc[indices].reset_index(drop=True)

    summary = pd.DataFrame({
        'population': df[cols].apply(lambda s: stat_fn(s.values)),
        'sample'    : sample[cols].apply(lambda s: stat_fn(s.values)),
    }).round(4)
    return sample, summary

N      = 1_000_000
df_log = pd.DataFrame({

    'response_ms'  : rng.exponential(scale=200, size=N).round(1),
    'payload_bytes': rng.integers(100, 5_000, size=N).astype(float),
})

)

§4 – Cluster Sampling#

Intuition: When individuals are naturally grouped (sessions, users, stores), sampling whole groups is often cheaper than sampling individuals. Select m clusters at random and use all (or a sub-sample of) their members. The statistical cost: units within a cluster are similar, so you get less diversity per observation than SRS – cluster SE > SRS SE for the same total n.

Confidence Interval – between-cluster variance:

\[\bar{x}_{cl} = \frac{1}{m}\sum_i \bar{x}_i, \quad SE = \frac{s_{\bar{x}}}{\sqrt{m}}, \quad \text{CI} = \bar{x}_{cl} \pm t_{\alpha/2,\,m-1} \cdot SE\]

Interview prompt: “You have clickstream data across 500 app sessions. Sampling individual events is expensive. Implement cluster sampling by session and show numerically why the variance is higher than SRS of the same total n.”

import numpy as np
import pandas as pd

rng = np.random.default_rng(42)

# ── Simulate session-level event data ─────────────────────────────────────────
n_sessions = 500
sizes      = rng.integers(20, 80, size=n_sessions)                       # variable session size
session_ids = np.repeat(np.arange(n_sessions), sizes)
df_events  = pd.DataFrame({
    'session_id' : session_ids,
    'duration_s' : rng.exponential(30, size=len(session_ids)).round(1),
    'converted'  : rng.binomial(1, 0.08, size=len(session_ids)).astype(float),
})
metric_cols = ['duration_s', 'converted']
print(f"Total events : {len(df_events):,} across {n_sessions} sessions")

# ── One-stage: sample whole sessions ──────────────────────────────────────────
m        = 50
selected = rng.choice(n_sessions, size=m, replace=False)
one_stage = df_events[df_events['session_id'].isin(selected)].copy()
print(f"\nOne-stage  : {m} sessions, {len(one_stage):,} events")

# ── Two-stage: subsample events within selected sessions ──────────────────────
parts = []
for sid in selected:
    grp = df_events[df_events['session_id'] == sid]
    parts.append(grp.sample(frac=0.5, random_state=42))

§5 – Bootstrap Resampling#

Intuition: Your sample is the best proxy for the population you have. Draw B samples with replacement from your data, compute the statistic on each – the spread of those B estimates approximates the true sampling distribution. Works for any statistic, requires no distributional assumptions, and is the standard approach for model performance uncertainty in industry.

Algorithm: resample with replacement B times -> compute stat -> take percentiles.

Confidence Interval (percentile method – no scipy needed):

\[\text{CI} = [\hat{\theta}^*_{\alpha/2},\; \hat{\theta}^*_{1-\alpha/2}]\]

where \(\hat{\theta}^*\) are the sorted bootstrap estimates and np.percentile does the work.

def bootstrap_ci(data, stat_fn, B=2000, confidence=0.95, seed=42):
    """
    Bootstrap confidence interval for any statistic.
    stat_fn : callable accepting a 1-D array, returning a scalar.
    Uses the percentile method -- no scipy needed.
    """
    rng_b = np.random.default_rng(seed)
    n     = len(data)
    idx        = rng_b.integers(0, n, size=(B, n))
    boot_stats = np.array([stat_fn(data[i]) for i in idx])
    alpha      = 1 - confidence
    lo, hi     = np.percentile(boot_stats, [100*alpha/2, 100*(1-alpha/2)])
    return lo, hi, boot_stats

def bootstrap_ci_df(df, cols, stat_fn=None, B=2000, confidence=0.95, seed=42):
    """
    Bootstrap CI for a custom statistic across multiple DataFrame columns.

    Parameters
    ----------
    df         : pd.DataFrame
    cols       : list[str]   -- metric columns to bootstrap
    stat_fn    : callable or None
                 Signature: stat_fn(arr: np.ndarray) -> scalar
                 Default: np.mean
    B          : int         -- bootstrap resamples
    confidence : float
    seed       : int

    -------
    results : pd.DataFrame with columns [observed, ci_lo, ci_hi, bootstrap_se]

def roc_auc(yt, yp):
    """Trapezoidal AUC (pure NumPy, no sklearn)."""
    order = np.argsort(yp)[::-1]
    yt_s  = yt[order]; yp_s = yp[order]
    pos   = yt.sum();  neg  = (1 - yt).sum()
    tp = np.cumsum(yt_s)   / pos
    fp = np.cumsum(1-yt_s) / neg
    tp = np.concatenate([[0], tp]); fp = np.concatenate([[0], fp])
    # Manual trapezoid (np.trapz renamed in NumPy 2.x)
    return float(np.sum((fp[1:] - fp[:-1]) * (tp[1:] + tp[:-1]) / 2))

§6 – Jackknife Resampling#

Intuition: Leave one observation out at a time, recompute the statistic on the remaining n-1 – repeat for every observation. The n leave-one-out estimates reveal how much each individual observation influences the result. Use jackknife for (a) bias correction and (b) finding influential observations. Only works reliably for smooth statistics (mean, ratio) – fails for median and quantiles. Bootstrap is the safer default; jackknife is the specialist tool.

Jackknife bias correction:

\[\text{bias} = (n-1)(\bar{\theta}_{(.)} - \hat{\theta}), \quad \hat{\theta}_{jack} = n\hat{\theta} - (n-1)\bar{\theta}_{(.)}\]

Confidence Interval:

\[SE_{jack} = \sqrt{\frac{n-1}{n}\sum_i(\hat{\theta}_{(i)} - \bar{\theta}_{(.)})^2}, \quad \text{CI} = \hat{\theta} \pm t_{\alpha/2,n-1} \cdot SE_{jack}\]

def jackknife_df(df, cols, stat_fn=None, confidence=0.95):
    """
    Jackknife bias correction and CI for multiple DataFrame columns.

    Parameters
    ----------
    df         : pd.DataFrame
    cols       : list[str]   -- metric columns (stat_fn must be smooth)
    stat_fn    : callable or None  (default np.mean)
    confidence : float

    Returns
    -------
    results : pd.DataFrame with [observed, bias, corrected, jk_se, ci_lo, ci_hi]
    """
    if stat_fn is None:
        stat_fn = np.mean

    n      = len(df)
    t_crit = 1.984                                                       # t(0.975, df=99)
    rows   = []
    for col in cols:
        arr       = df[col].values
        theta_hat = stat_fn(arr)
        jk_stats  = np.array([stat_fn(np.delete(arr, i)) for i in range(n)])
        theta_bar = jk_stats.mean()
        bias      = (n - 1) * (theta_bar - theta_hat)
        corrected = n * theta_hat - (n - 1) * theta_bar
        jk_var    = ((n - 1) / n) * np.sum((jk_stats - theta_bar) ** 2)
        jk_se     = np.sqrt(jk_var)
        lo, hi    = theta_hat - t_crit * jk_se, theta_hat + t_crit * jk_se
        rows.append({
            'column'   : col,
            'observed' : round(theta_hat, 4),
            'bias'     : round(bias, 6),
            'corrected': round(corrected, 4),
            'jk_se'    : round(jk_se, 4),
            'ci_lo'    : round(lo, 4),
            'ci_hi'    : round(hi, 4),
        })
    return pd.DataFrame(rows).set_index('column')

§7 – Weighted Sampling#

Intuition: When observations have unequal importance – due to class imbalance, oversampling, or survey design – weights restore representativeness. Each observation gets weight proportional to 1 / (selection probability). In DS interviews this almost always appears as class imbalance: the minority class needs more weight so the model does not ignore it.

Inverse class frequency weight: \(w_i = 1 / \text{count}(\text{class of } i)\)

Confidence Interval using Kish effective sample size:

\[\bar{x}_w = \frac{\sum w_i x_i}{\sum w_i}, \quad n_{eff} = \frac{(\sum w_i)^2}{\sum w_i^2}, \quad SE_w = \sqrt{\frac{s_w^2}{n_{eff}}}\]

Using \(n_{eff}\) instead of raw \(n\) correctly accounts for high variance in weights.

# ── §7 DataFrame API: weighted_ci_df ─────────────────────────────────────────
def weighted_ci_df(df, cols, weight_col, stat_fn=None, confidence=0.95):
    """
    Weighted statistic and CI (Kish effective n) for multiple columns.

    Parameters
    ----------
    df         : pd.DataFrame
    cols       : list[str]  -- metric columns
    weight_col : str        -- column of sampling weights
    stat_fn    : callable or None
                 Signature: stat_fn(arr, weights) -> scalar
                 Default: weighted mean via np.average
    confidence : float

    Returns
    -------
    results : pd.DataFrame with [weighted_stat, ci_lo, ci_hi, n_eff]
    """
    if stat_fn is None:
        stat_fn = lambda arr, w: float(np.average(arr, weights=w))

    w      = df[weight_col].values
    n_eff  = w.sum()**2 / (w**2).sum()                                  # Kish formula
    z      = 1.96 if confidence == 0.95 else -np.log((1 - confidence) / 2) / np.sqrt(2)

        w_stat = stat_fn(arr, w)
        w_var  = float(np.average((arr - w_stat)**2, weights=w))
        w_se   = np.sqrt(w_var / n_eff)
        lo, hi = w_stat - z * w_se, w_stat + z * w_se
        rows.append({

            'weighted_stat': round(w_stat, 4),
            'ci_lo'        : round(lo, 4),
            'ci_hi'        : round(hi, 4),
            'n_eff'        : round(n_eff, 1),
        })
    return pd.DataFrame(rows).set_index('column')

§8 – Stratified K-Fold Cross-Validation#

Intuition: K-fold splits the data into k equal folds, trains on k-1 folds, and validates on the remaining one – rotating until every fold has been the validation set. Stratified k-fold ensures each fold has the same class proportions as the full dataset. Without stratification, a small minority class can vanish entirely from a validation fold, making the CV score meaningless for that class.

Why this appears in DS interviews: It is the most common cross-validation pattern in production ML, yet sklearn’s StratifiedKFold hides all the logic. Interviewers use “implement it from scratch” to test whether you understand what it is actually doing.

Core logic: Assign fold IDs round-robin within each class, then rotate.

def stratified_kfold(df, target_col, k=5, seed=42):
    """
    Yields (train_indices, val_indices) for k stratified folds.
    Core idea: assign fold IDs round-robin within each class,
    then rotate which fold is the validation set.
    Column-agnostic: all feature columns are passed through unchanged.

        val_idx   = np.where(fold_ids == fold)[0]
        train_idx = np.where(fold_ids != fold)[0]
        yield train_idx, val_idx

§9 – Two-Sample Bootstrap & Permutation Test#

Intuition (bootstrap): To get a CI on the difference between two groups, resample each group independently with replacement, compute the difference of the statistic on each pair of resamples – the distribution of those differences is the bootstrap sampling distribution of the difference.

Intuition (permutation test): Under the null hypothesis that the two groups are exchangeable, shuffling which observations are labelled A vs B should produce a difference close to zero. Compute this shuffle-difference B times to build the null distribution, then check where the observed difference sits.

CI on the difference:

\[\text{CI} = [\delta^*_{\alpha/2},\; \delta^*_{1-\alpha/2}] \quad \text{where } \delta^* = \hat{\theta}_B^* - \hat{\theta}_A^*\]

Bootstrap p-value (one-sided): \(p = P(\delta^* \leq 0)\)

Permutation p-value (two-sided): \(p = P(|\delta_{null}| \geq |\delta_{obs}|)\)

# ── Bootstrap CI on the difference (vectorised) ───────────────────────────────
def bootstrap_diff_ci(a, b, stat_fn=np.mean, B=10_000, confidence=0.95, seed=42):
    """
    Bootstrap CI for stat_fn(b) - stat_fn(a).
    Resamples each group independently -- vectorised for speed.
    """
    rng_b  = np.random.default_rng(seed)
    idx_a  = rng_b.integers(0, len(a), size=(B, len(a)))
    idx_b  = rng_b.integers(0, len(b), size=(B, len(b)))
    boot_d = b[idx_b].mean(axis=1) - a[idx_a].mean(axis=1)
    alpha  = 1 - confidence
    lo, hi = np.percentile(boot_d, [100*alpha/2, 100*(1-alpha/2)])
    p_one  = float(np.mean(boot_d <= 0))                               # P(B <= A), one-sided
    return lo, hi, p_one, boot_d

# ── Permutation test (two-sided, exact null) ──────────────────────────────────
def permutation_test(a, b, B=10_000, seed=42):
    """
    Tests H0: mean(a) == mean(b) by permuting group labels.
    Returns two-sided p-value and the null distribution.
    """
    rng_p    = np.random.default_rng(seed)
    combined = np.concatenate([a, b])
    n_a      = len(a)
    obs      = b.mean() - a.mean()
    perms    = np.array([rng_p.permutation(len(combined)) for _ in range(B)])
    null_d   = (combined[perms[:, n_a:]].mean(axis=1) -
                combined[perms[:, :n_a]].mean(axis=1))
    p_two    = float(np.mean(np.abs(null_d) >= np.abs(obs)))
    return p_two, null_d

        null_d   = np.array([
            stat_fn(combined[p[len(a):]]) - stat_fn(combined[p[:len(a)]])
            for p in (rng_b.permutation(len(combined)) for _ in range(B))
        ])
        perm_p = float(np.mean(np.abs(null_d) >= np.abs(obs_diff)))

        rows.append({
            'column'     : col,
            'obs_diff'   : round(obs_diff, 4),
            'ci_lo'      : round(lo, 4),
            'ci_hi'      : round(hi, 4),
            'boot_p'     : round(boot_p, 4),
            'perm_p'     : round(perm_p, 4),
            'significant': bool(lo > 0),
        })
    return pd.DataFrame(rows).set_index('column')

Common mistakes:

  • Using a one-sided p-value when the test is not directional – report two-sided unless the alternative was specified beforehand

  • Reporting only a p-value without a CI – the CI tells you whether the effect is practically meaningful, not just statistically significant

  • Resampling both groups from the combined pool in the bootstrap – groups must be resampled independently (combine-and-resample is the permutation test, not the bootstrap)

Interview Q&A#

Q: When does stratified sampling beat simple random sampling? A: When the strata differ in the quantity you are estimating and you can define them before sampling. Stratifying removes between-stratum variance from the estimator, so the standard error drops without any increase in sample size. The gain is largest when strata are internally homogeneous and mutually very different; if the strata all look the same, stratifying buys nothing.

Q: A rare segment is 0.5% of users and you need per-segment estimates. A: Oversample that stratum and weight it back. A proportional sample gives too few rows for a usable interval, so I’d allocate disproportionately — enough rows in the rare stratum to hit the precision target — then apply inverse-probability weights when computing the overall estimate. Reporting the unweighted overall mean after disproportionate sampling is the classic error.

Q: Bootstrap or a closed-form confidence interval? A: Closed form when the assumptions hold and the statistic has known sampling theory — a mean on a decent sample size. Bootstrap when the statistic is awkward: a median, a ratio, a 90th percentile, an AUC. The bootstrap costs compute and assumes the sample represents the population, so it does not rescue a biased sample — it only handles an unknown sampling distribution.

Q: Why stratify a K-fold split? A: To keep the class ratio stable across folds. With an imbalanced target, plain K-fold can produce folds with almost no positives, which makes fold metrics wildly variable and can leave a fold where a metric is undefined. Stratification removes that variance source and costs nothing.

Q: Cluster sampling is cheaper. What is the catch? A: The design effect. Units inside a cluster are correlated, so the effective sample size is smaller than the row count and naive standard errors are too narrow. If you sample 50 stores and analyse 50,000 transactions as if independent, every interval is wrong. Analysis has to account for clustering.

Gotchas#

  • Bootstrapping a time series with an i.i.d. resample destroys the autocorrelation; use a block bootstrap

  • df.sample() without random_state is unreproducible — always seed

  • Sampling after filtering changes the population you are inferring about; be explicit about which frame the sample represents

  • A permutation test answers “could this arise by chance under the null?”, not “how large is the effect?” — pair it with an interval
